## التغيير

- `src/i18n/format.ts` جديدٌ: `parseAmountToMinor` (أرقامٌ عربيةٌ-هنديةٌ وأورديةٌ · `٫` و`,`) · `formatMoney` · `formatDate` · `enumLabel` · `localizedTitle` — كلُّها بـ`Intl` وبالـlocale النشطِ.
- `store/order-form.ts`: `offered_price = { amount_minor, currency: "SAR" }`.
- الشاشاتُ تقرأُ حقولَ العقدِ الفعليّةَ، والمحاكاةُ في الاختباراتِ (وحدةٌ وe2e) صُحِّحَت إلى أشكالِ العقدِ نفسِها.
- CSS: شبكةُ عمودينِ عندَ ≥768px **داخلَ** عمودِ الحاسوبِ (720px — قرارُ XR-8.3a محفوظٌ؛ محاولةُ 960px أسقطَها اختبارُهُ فأُلغيت).
- الجوّالُ وتيليجرامُ (<768px) لا يتغيّرُ تخطيطُهما.
