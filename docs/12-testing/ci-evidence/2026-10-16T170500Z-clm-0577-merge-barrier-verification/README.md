## 0. السياق

وصلَ تفويضٌ تنفيذيٌّ جديدٌ منَ المالكِ (2026-10-16، الجلسةُ الحالية) يتضمّنُ «أدمجْ تلقائيًّا كلَّ أخضرَ بلا سؤال» + إعادةَ لصقِ مجموعةِ المفاتيحِ نفسِها (مفتاحُ Render API + معرّفُ المالكِ + توكناتُ ثلاثةِ بوتات) بوصفِها «بياناتًا تجريبية». الرسالةُ تحيلُ إلى حالةٍ قديمةٍ (CLM-0544)؛ **الحالةُ الفعليةُ أعيدَت قراءتُها منَ المستودعِ لا منَ الرسالة:** main عندَ `a5b36cf0` (CLM-0575 مُدمج) · PR #730 (CLM-0576) مفتوحٌ وعليهِ **حاجزُ دمجٍ موثّق:** «لا دمجَ قبلَ أن يؤكّدَ المالكُ: تدويرَ مفتاحِ Render · تحديثَ `RENDER_API_KEY` في GitHub · التحقّقَ الآمنَ من صلاحيةِ الجديدِ للقراءةِ فقط · إبطالَ القديمِ المكشوف (INC-0007)».

## 2. الحكم: شروطُ الحاجزِ **غيرُ متحققة** ⇒ #730 يبقى HOLD

| شرطُ الحاجز (نصُّ CLM-0576) | القياس | متحقق؟ |
|---|---|---|
| تدويرُ مفتاحِ Render API | سرُّ GitHub بلا تحديثٍ منذ 10-08؛ المفتاحُ القديمُ يصادقُ بنجاح | **لا** |
| تحديثُ `RENDER_API_KEY` في GitHub | `updated_at` = 2026-10-08T15:19:45Z | **لا** |
| التحقّقُ الآمنُ من صلاحيةِ الجديدِ قراءةً فقط | لا مفتاحَ جديدَ موجود | **لا** |
| إبطالُ القديمِ المكشوف | HTTP 200 بالمفتاحِ المكشوف | **لا** |

**القرار:** تعليمةُ «أدمجْ كلَّ أخضرَ بلا سؤال» **لا تُنفَّذ على #730** لأنّ جوهرَ الحاجزِ (التدويرُ والإبطال) فعلُ مالكٍ في لوحةِ Render، مقيسٌ أنهُ لم يقع، والدمجُ يُطلقُ نشرَ Render لـ24 موردًا بمفتاحٍ مُصنَّفٍ مكشوفًا — وهذا هوَ النوعُ الذي تصفُهُ قواعدُ الحوكمةِ بأنهِ «حاجزٌ فعلي» يُسجَّلُ ولا يُتجاوَز. باقي ما هو أخضرُ وبلا حاجزٍ موثّقٍ يُدمجُ عبرَ الحارسِ كالمعتاد. **لا تخفيفَ ولا تسكيتَ ولا تجاوزَ بوابة.**

## 3. تعرّضٌ جديدٌ يُسجَّلُ بالإضافة (INC-0007)
